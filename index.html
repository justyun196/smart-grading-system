📝 更新日志 v1.0.3.3 (2026-11-06)

• 单题批改新版页面上线：标签页工作台风格（工作台/批改设置/批改过程/API管理/判断依据录制/豆包元素录制/判分复用），作为单题批改默认入口；旧版页面永久保留，新旧版互有切换入口

• 判分复用增强模式（API，可选开关）：AI 不再每张卡都评分——先识别答案，与本地判定记录比对，见过的直接复用历史分数，没见过的才调 API 评分并留档；减少 API 调用次数，同时消除重复判分的 AI 随机波动

• 按题分类逻辑：填空题逐空收集答案与标准答案比对给分，按「每空答案→对错」留档；主观题首次由标准答案生成给分点，之后识别答题要点按要点组合比对复用

• 一题一组 / 5题一组 / 批改 / 测试全入口支持；空答案直接记 0 分不耗 API；识图失败自动回退整卡带图评分不中断

• 判定记录无限期保留、不设上限：记录查看器按题目→给分位展示（原图缩略图/答案/分数/复用次数），支持单条删除与清空

• 成效统计面板：批改卡数、复用命中、命中率、少调评分 API 次数、实调 API 次数

• API 按功能固定：识图对照/带图评分（需图片）与文本评分（不用图片）在 API 管理中分别指定，配置数据单题/多题共享，功能配置按页面独立

• 批改过程显示升级：结构化分级日志（阶段横幅/步骤/成功/错误/明细，带时间戳）；得分可视化——单卡为每空色块板（对绿/错红，带答案文字与「复用」角标），5 卡为得分矩阵表（行=给分位、列=卡1-5、底部每卡总分与复用数）；历史记录回看同样结构化，AI 原始输出折叠收纳
