📝 【「云上批阅」v1.0.3.4 发布】核心升级：激活码远程下发 + 按 token 计费

功能更新：

  • 激活码远程下发（方案B）：管理员在后台生成激活码并绑定共享豆包 Key，用户在软件「API 管理」页输码即可激活；客户端不内置 Key，每次批改远程校验，吊销/过期/超额即时停用。
  • 按 token 用量计费：批改前先校验不扣（tokens=0），模型返回后按 total_tokens 原子累加；超限/吊销/过期在下一次请求前即拦截。

修复：

  • 修复部分电脑首页「只改一题 / 多题 / 退出登录」全部无反应、未登录也不跳登录页（初始化容错 + 存储安全封装）。
  • 修复部分安装路径下页面跳转 / 相对资源加载失败（标准 file:/// URI）。
  • 修复应用列表 / 快捷方式图标空白（假 ICO → 真多尺寸 ICO）。
  • 修复激活码前置校验漏洞（先加载 → 统一校验 → 再扣费）。

安装器：

  • 默认安装路径改为 %ProgramFiles%\云上批阅（系统级标准位置，需管理员权限）。
  • 安装完成自动授予安装目录写权限，保证 config / temp / runtime_files 可写、自动更新可用。
  • 安装器 / 启动器 / 卸载器重新内嵌真图标。
