📝 【「云上批阅」v1.0.3.7 发布】核心升级：缺 WebView2 也能自动定位并引导安装

核心升级：

  • 问题机根因定性：最常见的「页面能显示、但所有按钮/脚本全没反应」实为缺少 WebView2 运行时（Windows Server 等系统默认不预装，界面回退旧内核无法执行现代脚本），并非安全软件拦截或地址问题。
  • 启动自动检测 + 引导安装：界面无法加载时先判定是否缺 WebView2；缺失则弹窗一键打开官方下载页（约 100MB，安装后重启软件生效），不用再手动排查。
  • 诊断文案更准确：区分三种根因（缺组件 / JS 引擎被禁 / 未知），反馈日志一眼可辨。
